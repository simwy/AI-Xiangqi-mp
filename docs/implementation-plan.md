# 完整实现计划

以已确认的竖屏 UI 和一局一条 JSON 档案为准，正式存储采用 uniCloud。

1. [已实现] 实现可复用象棋规则、FEN、规范着法、残局校验及逐步棋谱导入校验。
2. [已实现] 实现 uniCloud schema、受签名保护的数据网关、版本校验和运行租约；本地演示使用明确隔离的文件存储。
3. [已实现] 实现模型数据库配置、think 参数适配、管理员接口、持续调度和异常恢复。
4. [已实现] 每次请求先保存调用状态；每次合法落子先持久化成功，再发布新局面；失败暂停，不丢弃未完成棋局。
5. [已实现] 实现解说、语音原文件归档、逐步回放、导入、残局续弈、投票、整局 ZIP 导入导出。
6. [已实现] 将原型迁移至 uni-app 观战页，增加可运行的 H5 与微信/抖音小程序构建配置及管理界面。
7. [已验证：20 项测试、三端构建及浏览器回放] 执行规则、并发存储、恢复、接口和文件导入导出测试，构建三个目标；记录云端与真实密钥仍需验证的部分。

本地完成实现不等于已部署云函数或已完成供应商真实调用。正式运行必须配置服务空间、网关密钥、管理员令牌和模型/语音凭据。
