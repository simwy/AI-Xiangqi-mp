手动摆残局

选择棋子后点击格点放置；选择“擦除”移除棋子。上方为黑方、下方为红方；服务端在保存时检查九宫、兵卒位置及将帅照面。

草稿不会打断直播；保存后可点击“下局播出”。导入带棋步的棋局需先从指定步创建续弈。

导入棋局

JSON 用于纯棋谱；含原声时导入完整 ZIP。导入重新分配本库棋局 ID，保留原始来源。
