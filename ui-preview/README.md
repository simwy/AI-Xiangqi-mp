# AI 象棋竖屏 UI 预览

当前确认的视觉与交互原型，独立于 uni-app 应用入口。后续正式实现需迁移为 uni-app 通用组件，并接入服务端。

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080/ui-preview/`。

- 点击右上角开启落子音效。
- 点击棋盘查看炮横跨六路的抬起、掠行和重落动画；双击查看绝杀演出。
- 豆包 banner 下方的三个按钮打开历史、回看及投票浮层。
- 双方形象轻微浮动，金色圆环显示示例思考时间与状态。

当前棋局、计时、解说字幕、历史与投票均为演示数据；不调用模型或语音 API，不保存真实投票。回放仅展示六步移动示例。页面使用浏览器音频与动画 API，尚不能作为已完成的小程序适配。

## 预览素材

- `assets/reference.png`：用户提供的参考截图，当前仅用于本地视觉评审中的人物、棋子及材质裁切；正式发布前替换为独立素材。
- `assets/deepseek.svg`：来自 [DeepSeek 官方仓库](https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg) 的临时模型标识；并非已完成的角色原画。
- `assets/wood-stone-impact.wav`：本项目生成的木质撞击合成音，48 kHz 单声道，非实物录音。

本目录不包含任何 API 密钥或本地预览会话令牌。
